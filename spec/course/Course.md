| Item | Detail |
|------|--------|
| Primary Key | `pkid` int IDENTITY |
| Foreign Keys | `Partner_pkid` → `Partner.pkid` (NOT NULL); `CourseGroup_pkid` → `CourseGroup.pkid` (nullable); `PublishStatus_pkid` → `PublishStatus.pkid` (NOT NULL) |
| Required Fields | `Title`, `CourseId`, `ProdCourseId`, `FriendlyUrl`, `DisplayOrder`, `Partner_pkid`, `PublishStatus_pkid`, `ScheduleOn`, `ScheduleOff`, `Hour`, `ListPrice`, `LearningCredit`, `CanRepeat` |
| N-N Relationships | `CourseInCertification` (↔ Certification), `CourseJobCategories` (↔ JobCategory) — **deferred**, see below |
| Primary-Foreign Links | `CourseFAQ`, `CourseRelatedLink`, `CourseRecomm`, `HotCourse` reference Course — **deferred** (no child CRUD/routes exist) |
| Query Filters | keyword; `Partner_pkid`; `CourseGroup_pkid`; `PublishStatus_pkid`; `ScheduleOn` range; `ScheduleOff` range; `CanRepeat` |
| Default Sort | `DisplayOrder ASC, pkid DESC` |
| UNIQUE constraints | none on Course (CourseId is **not** unique in the schema) |

### Scope of this build

**In scope (this pass):** full CRUD for all Course scalar columns + the 3 FK dropdowns;
list with FK-label columns; query filter drawer; detail page (with the existing
**QR code** in 基本資料); backend + frontend unit tests.

**Deferred (documented, not built now):**
- **N-N** (Certifications, JobCategories) — needs new `certifications` + `job-categories`
  lookup endpoints that don't exist yet.
- **Primary-Foreign nav links** to `CourseFAQ` / `CourseRelatedLink` / `CourseRecomm` /
  `HotCourse` — those child entities have no list feature/route to link to.
- **Copy action** and **print-PDF** (present in the reference sample, not requested here).

These are called out so the gate decision below is informed; say the word to fold N-N in.

## Required Fields

Required (NOT NULL, excluding IDENTITY PK): `Title`, `CourseId`, `ProdCourseId`,
`FriendlyUrl`, `DisplayOrder`, `Partner_pkid`, `PublishStatus_pkid`, `ScheduleOn`,
`ScheduleOff`, `Hour`, `ListPrice`, `LearningCredit`, `CanRepeat`.

Optional (nullable): `OfficialTitle`, `CourseGroup_pkid`, `Material`, `Objective`,
`Target`, `Prerequisites`, `Outline`, `TowardCertOrExam`, `Note`, `OtherInfo`.

## Foreign Keys

- **Partner_pkid** → `Partner.pkid` (NOT NULL). Alias `PartnerPkid`. Label = `Partner.Name`.
  Lookup `GET /api/lookups/partners` (ordered by `DisplayOrder`). List column 原廠.
- **CourseGroup_pkid** → `CourseGroup.pkid` (nullable — allow 無). Alias `CourseGroupPkid`.
  Label = `CourseGroup.Description`. Lookup `GET /api/lookups/course-groups`. List column 課程群組.
- **PublishStatus_pkid** → `PublishStatus.pkid` (NOT NULL, `tinyint` → `byte`). Alias
  `PublishStatusPkid`. Label = `PublishStatus.Description`. Lookup `GET /api/lookups/publish-statuses`. List column 上架狀態.

Read model carries the joined labels `PartnerName`, `CourseGroupDescription`,
`PublishStatusDescription` (LEFT JOIN for the nullable CourseGroup).

## Foreign-Primary Links
Detail page may link out to `/partners/{PartnerPkid}`, `/course-groups/{CourseGroupPkid}`
(when set), `/publish-statuses/{PublishStatusPkid}` — those detail routes all exist.

## Primary-Foreign Links
**Deferred.** `CourseFAQ`, `CourseRelatedLink`, `CourseRecomm`, `HotCourse` reference
`Course.pkid`, but none has a list feature/route today, so no nav buttons are built.

## N-N Relationships
**Deferred.** `CourseInCertification` (`Course_pkid`,`Certification_pkid`) and
`CourseJobCategories` (`Course_pkid`,`JobCategory_pkid`) are pure junctions. Building them
requires new `certifications` and `job-categories` lookup endpoints + multi-select UI +
delete-then-reinsert sync. Not included in this pass.

---

## Query Filters (`POST /api/courses/query`)

- **keyword** — LIKE on `Title`, `OfficialTitle`, `CourseId`, `ProdCourseId`, `FriendlyUrl`
  (short identifying columns only; the nvarchar(max)/4000 text columns are excluded).
- **partnerPkid** (`short?`) — exact match on `Partner_pkid`.
- **courseGroupPkid** (`short?`) — exact match on `CourseGroup_pkid`.
- **publishStatusPkid** (`byte?`) — exact match on `PublishStatus_pkid`.
- **scheduleOnFrom / scheduleOnTo** (`DateOnly?`) — inclusive range on `ScheduleOn`.
- **scheduleOffFrom / scheduleOffTo** (`DateOnly?`) — inclusive range on `ScheduleOff`.
- **canRepeat** (`bool?`) — tri-state (全部 / 是 / 否), exact match on `CanRepeat`.

## Backend Notes

### Models
`Course` (read): all scalar columns with `PartnerPkid` / `CourseGroupPkid` /
`PublishStatusPkid` aliases **plus** joined `PartnerName`, `CourseGroupDescription`,
`PublishStatusDescription`. `CourseRequest` (write): every writable column, no joined
labels. `CourseQuery`: the filter fields above (all nullable).

Type mapping: `int IDENTITY`→`int` PK; `nvarchar/varchar`→`string`/`string?`;
`smallint`→`short`; `tinyint`→`byte`; `bit`→`bool`; `decimal(9,0)`/`decimal(9,1)`→`decimal`;
`date`→`DateOnly` (handler already registered in `Program.cs`).

### SQL — SELECT
```sql
SELECT c.pkid, c.Title, c.OfficialTitle, c.CourseId, c.ProdCourseId, c.FriendlyUrl,
       c.DisplayOrder, c.Partner_pkid AS PartnerPkid, c.CourseGroup_pkid AS CourseGroupPkid,
       c.PublishStatus_pkid AS PublishStatusPkid, c.ScheduleOn, c.ScheduleOff, c.Hour,
       c.ListPrice, c.LearningCredit, c.Material, c.Objective, c.Target, c.Prerequisites,
       c.Outline, c.TowardCertOrExam, c.Note, c.OtherInfo, c.CanRepeat,
       p.Name AS PartnerName, g.Description AS CourseGroupDescription,
       s.Description AS PublishStatusDescription
FROM Course c
INNER JOIN Partner p ON p.pkid = c.Partner_pkid
LEFT JOIN CourseGroup g ON g.pkid = c.CourseGroup_pkid
INNER JOIN PublishStatus s ON s.pkid = c.PublishStatus_pkid
```
INSERT/UPDATE writable columns = all NOT NULL + nullable scalar columns above (exclude
IDENTITY pkid and the joined labels). INSERT ends with `SELECT CAST(SCOPE_IDENTITY() AS int)`.

No RowAudit (this repo has none). No nchar columns → no RTRIM.

## Frontend Notes

Feature folder `features/courses/` (model + service live here, per repo convention).

### List
- Columns exactly as requested: 主代碼, 顯示順序, 簡介代碼, 科目代碼, 課程名稱, 原廠,
  課程群組, 上架狀態, 上架日期, 下架日期, 時數, 定價, 點數, 允許重聽 + 操作 (view/edit/delete).
- FK columns render the joined labels (`partnerName`, `courseGroupDescription`,
  `publishStatusDescription`) — no extra lookup calls needed for display.
- Filter drawer (`p-drawer`, right): keyword input; Partner / CourseGroup / PublishStatus
  `p-select` (`appendTo="body"`, `[filter]` at 10+); ScheduleOn & ScheduleOff `p-datepicker`
  range pairs; CanRepeat tri-state `p-select` (全部/是/否).
- Session storage: `course-list-filters`, `course-list-sort`, `course-list-page`.
- Default sort `displayOrder ASC`. Date filters serialize with **local** components.
- Delete confirm: ``確定要刪除主代碼 <b>${item.pkid}</b>「${item.courseId}」？``

### Form
- Reactive Forms; `forkJoin` the 3 lookups on init (+ `getById` in edit mode).
- Widgets: text inputs (Title, OfficialTitle, CourseId, ProdCourseId, FriendlyUrl);
  `p-inputNumber` (DisplayOrder, Hour, ListPrice, LearningCredit); `p-select` (Partner,
  CourseGroup[showClear], PublishStatus); `p-datepicker` (ScheduleOn, ScheduleOff);
  `p-textarea` (Material, Objective, Target, Prerequisites, Outline, TowardCertOrExam,
  Note, OtherInfo); `p-checkbox [binary]` (CanRepeat).
- `pkid` is IDENTITY — held on the component, folded into the request on save (not a control).
- `date` ⇄ `Date`: convert 'yyyy-MM-dd' string ↔ `Date` on load/save using **local** components.
- Save error → 「儲存失敗」 toast; success → navigate to detail.

### Detail
- Read-only cards. **基本資料** card hosts `<app-course-qr-code [pkid] [courseId]>`
  (already built + tested). FK values shown as labels with links to their detail pages.

### Sidebar
- New item **課程 Course** → `/courses`, under existing group **課程管理 Course**
  (alongside 合作廠商 Partner, 課程群組 CourseGroup).

### Routes
`features/courses/courses.routes.ts`: `''` (list), `'new'` (form), `':id/edit'` (form),
`':id'` (detail) — `/new` before `/:id`.
